# Versify Presentation

Public Windows presentation software for churches.

[Download the latest Presentation installer](https://github.com/kelvinmacwan007/versify-releases/releases/latest)

Download and run the Presentation Setup EXE. Songs and complete Bibles sync from https://versify.knorvix.com while online and remain available offline. Use File > Sync Live Library Now for a manual refresh. Use Help > Check for Updates to install a new application release.

This edition contains no AI model, song administrator, or catalog editing tools. Only the owner signs into the separate private AI Administrator to publish songs to the live library. Public installations fetch those songs while online.

This repository contains public installers, update metadata, and checksums only. Source code and the AI Administrator installer remain private.
